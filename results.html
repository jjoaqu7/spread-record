How picks are published & graded

Flagged team covers the published spread; full-game final score including overtime. Pushes recorded separately. Both teams flagged: no pick. Cancelled games void; postponed games remain pending.

Publication target: 4:00 a.m. America/Toronto. Only picks published at least 30 minutes before game start are eligible. Original predictions are attached to dated immutable GitHub releases.

Cover margin = selected team’s final score + published spread − opponent’s final score. Positive is a win, negative is a loss, and zero is a push. A final score is shown away team first, then home team.

This page is a reproducible results summary. Original prediction attachments remain locked. GitHub allows deletion of an entire release, so this is not an indestructible archive. Results reflect the last check shown above.
