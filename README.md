### How the record works

Flagged team covers the published spread; full-game final score including overtime. Pushes recorded separately. Both teams flagged: no pick. Cancelled games void; postponed games remain pending.

Publication target: **4:00 a.m. America/Toronto**. Only picks published at least **30 minutes before game start** count. Cover margin = selected team’s final score + published spread − opponent’s final score.

[Original predictions](https://github.com/jjoaqu7/spread-record/releases) · [Raw results](results.json)

Results are a reproducible summary. Original prediction attachments stay locked in immutable releases. Every published pick remains visible, including losses and ineligible picks. GitHub permits deletion of an entire release, so this is not an indestructible archive.
