# Spread record

A public record of pregame spread predictions and their results.

**Status: automation is being configured. No predictions have been published yet.**

- Publication target: **4:00 a.m. America/Toronto**, including daylight-saving changes.
- Only picks published at least **30 minutes before game start** are eligible.
- Picks back the flagged team to cover its published spread. Both teams flagged: no pick.
- Original predictions will be attached to dated **immutable GitHub releases**, with GitHub publication timestamps.
- Full-game final scores determine **win, loss or push**. Cancelled games are void; postponed or unverified games remain pending.
- Every published pick remains in the record, including losses. Results link to ESPN and the original prediction release.

The results table will be a reproducible summary. Locked prediction attachments are evidence of the original picks. GitHub permits deletion of an entire release, so this is not an indestructible archive.
